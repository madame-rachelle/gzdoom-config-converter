# uzdoom-config-converter
Converts a uzdoom.ini to its keyconf, defbinds, and defcvars equivalent

Usage: `./convert-config <gamename> <modname>`
modname is optional

examples:
- `./convert-config Hexen`
- `./convert-config Doom Stronghold`
